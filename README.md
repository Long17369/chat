# 聊天软件

该项目是一个基于 **Protobuf** 和 **Qt** 实现的聊天软件，使用 **CMake** 进行构建和管理。

## 技术栈

- [Qt](https://www.qt.io/)：跨平台图形界面开发框架
- [Protobuf](https://developers.google.com/protocol-buffers)：高效的数据序列化协议
- [CMake](https://cmake.org/)：跨平台的构建工具

## 功能简介

- 实时聊天
- 消息序列化与反序列化
- 跨平台支持

## 构建与运行

```bash
git clone <仓库地址>
cd chat
mkdir build && cd build
cmake ..
make
./chat
```
